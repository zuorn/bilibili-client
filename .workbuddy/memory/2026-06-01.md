# 2026-06-01 工作日志

## 收藏功能修复（第二轮）

**问题**: `add-to-favorites` 保存时返回 `code: 2001000, message: 参数错误`

**根因**: 
1. 用户选择"默认收藏夹"时，`add_media_ids` 参数被过滤掉（之前代码用 `fid=-1` 的合成默认收藏夹，`id > 0` 过滤掉了-1）
2. `add_media_ids` 是 B站 API 的必填参数，缺失导致 2001000

**修改文件**:
1. `src/main/ipc/favorites.js` `add-to-favorites` handler (第416-431行)
   - `add_media_ids` 现在始终包含在 WBI 签名和 POST body 中（默认空字符串）
   - 过滤条件从 `id > 0` 改为 `id >= 0`

2. `src/main/ipc/favorites.js` `get-favorites-folders` handler (第356-390行)
   - 不再创建合成默认收藏夹（之前 fid=-1 的假数据）
   - 改为通过名称"默认收藏夹"检测真正的默认收藏夹
   - API 未返回时兜底创建 fid=0 的合成默认

3. `src/pages/player.html` `saveToFavorites` (第3639行)
   - 条件从 `> 0` 改为 `>= 0`，允许 fid=0 的合成默认通过
