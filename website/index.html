不只是浏览器，更是播放器

为「看番」这件小事，做了很多特别的事

为播放而生的桌面播放器

不只是换个窗口看视频。Bilibili Client 内置独立播放窗口，同时支持 外置 MPV 与 内置播放器 双引擎：自动探测本机 MPV 可执行文件，找不到时无缝回退内置播放器，开箱即用。

播放时直接拉取 B 站 DASH 最高清晰度音视频直链（跳过网页解析，启动更快），并把弹幕 XML 实时转换为 ASS 字幕轨与画面同步渲染；观看进度自动记录并上报观看历史，下次打开接着看，播放窗口的位置、大小与全屏状态也会一并记忆还原。

MPV 硬解 DASH 直链 弹幕同步 进度续播 窗口记忆

实时弹幕
