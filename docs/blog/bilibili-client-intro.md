# 我给 B 站写了个桌面客户端：安装包 2.85MB，纯键盘操作，支持 Anime4K 画质增强

> 项目地址：https://github.com/zuorn/bilibili-client（开源，MIT 协议，求 Star）

作为一个每天泡在 B 站的重度用户，我一直想要一种更轻快、更专注的看视频方式：打开就刷、说看就看、手不离键盘、想边看边干别的也不受拘束。

于是我动手写了一个：**Bilibili Client** —— 一个基于 Tauri 2 的哔哩哔哩桌面客户端。它不追求大而全，只在体积、性能和操作效率上下功夫。这篇文章介绍它几个最值得尝试的点。

---

## 一、小到离谱的安装包：2.85MB

先说结论：**整个安装包只有 2.85MB，主程序 exe 只有 7MB。**

作为对比：

| 客户端 | 典型安装包体积 |
| --- | --- |
| 基于 Electron 的第三方 B 站客户端 | 80 ~ 150MB |
| 主流 Electron 桌面应用（VS Code、Discord 等） | 80MB+ |
| **Bilibili Client** | **2.85MB** |

为什么能这么小？

1. **Tauri 2 + 系统 WebView**：不用打包 Chromium，Windows 上直接复用系统自带的 WebView2，体积和内存都省了；
2. **后端是 Rust**：网络请求（reqwest）、Cookie 管理、弹幕转换、DASH 流合并（自研 mp4 remux，甚至不需要捆绑 ffmpeg）全部在 Rust 侧完成；
3. **渲染层是原生 JS**：没有 React、没有 Vue、没有打包工具，所有脚本按依赖顺序用 `<script>` 标签加载。没有 node_modules 进安装包，也就没有动辄几十 MB 的运行时。

安装完之后，你会发现它启动几乎是秒开的。

## 二、性能：Rust 后端 + 无框架前端的组合拳

小体积只是副产品，真正的收益在运行时：

- **内存占用低**：没有 Chromium 捆绑，没有虚拟 DOM 框架，渲染层就是浏览器原生能力的直接调用；
- **网络与解码在 Rust 侧**：B 站的 WBI 签名、Cookie 注入、音视频流的预取与合并都由 Rust 完成，前端只管渲染；
- **自研 DASH remux**：B 站的高清流是音视频分离的 DASH 格式，项目用 mp4 crate 写了一个原生 remux 模块（含 fMP4 分片解析和 faststart 重排），优先原生处理，不依赖外部 ffmpeg，长视频音画同步问题也在这个层面解决了；
- **无限滚动不卡顿**：首页推荐、热门、动态、历史记录都是无限滚动加载，配合鼠标悬停视频卡片即时预览，流畅度在低端机器上也很能打。

一句话：**把浏览器还给它该干的事（渲染），把脏活累活交给 Rust。**

## 三、Vim 党狂喜：全站纯键盘操作

这是我个人的私心功能，参考了 Surfingkeys 的交互：

- **按 `f`**：页面上所有可点击元素立即生成访问标签，按下对应字母即可"点击"。翻页、切换 Tab、点赞、收藏，全程手不离键盘；
- **`gg`** 回到顶部，**`u`** 返回，**`r`** 刷新；
- **`d`** / **`e`** 上下滚动半页，刷动态、刷推荐流比滚轮还快；
- **`/`** 直接聚焦搜索框。

而且这些快捷键**不是写死的** —— 设置页面内置了快捷键录制界面，你可以按自己的习惯重新绑定。如果你是 Vim / Surfingkeys 用户，打开这个客户端的第一分钟就会觉得"这就是为我做的"。

## 四、播放窗口：独立窗口 + Anime4K + 一整套细节

播放体验是这个客户端打磨最久的地方。点击视频会打开一个**独立的播放器窗口**，脱离主界面，你可以把它拖到屏幕任意角落边看视频边干别的。

### 画质与播放

- **DASH 流播放**：预取音视频分离的高清流，独立同步播放；
- **Anime4K WebGL 画质增强**：内置 A4k 着色器，低分辨率番剧实时超分，老番也能看得很舒服；
- **弹幕支持**：B 站弹幕加载，还支持转换为 ASS 字幕；
- **MPV 外接**：喜欢 MPV 的用户可以直接调用外部 MPV 播放；
- **进度条缩略图预览**：鼠标悬停进度条即可看到对应画面。

### 窗口操作（这块细节最多）

- 窗口**按视频比例自动调整大小**，不会出现黑边或拉伸；
- 鼠标左键直接**拖动窗口**，双击全屏/退出全屏；
- **`WASD` 移动窗口位置**，`Ctrl + Tab` 把窗口甩到下一个显示器；
- 鼠标**滚轮调音量**、按住 `Ctrl` 滚轮调进度、按住 `Alt` 滚轮调整窗口大小；
- 播放时自动隐藏鼠标，控制栏鼠标不动 1 秒后自动隐藏；
- 停在播放器上展开侧边栏：视频简介、合集自动连播、相关推荐、评论区（最热/最新两个 Tab，可发评论、回复、点赞、删除）。

### 其他贴心细节

- 历史进度记忆：看了一半的视频，下次点开自动从上次的位置继续；
- 右键菜单可以直接把正在播放的视频**下载到本地**（异步下载，关掉窗口也继续下）；
- 播放器快捷键齐全：空格暂停、方向键快进/音量、`m` 静音、`v` 关弹幕、`q` 退出。

## 除了这四点，还有

- 首页推荐 / 热门（综合、每周必看、入站必刷、排行榜）/ 综合动态 / 追番 / 影视 / UP 主空间 / 搜索，B 站主功能基本全覆盖；
- 我的页面：历史记录、稍后再看、收藏夹增删改查与排序、追番管理；
- 二维码扫码登录，Cookie 持久化，不用重复登录；
- 深色主题；
- 系统托盘（双击唤起主窗口）；
- **自动更新**：启动时自动检查新版本，OSS + GitHub Releases 双源，minisign 签名校验。

下载 `Bilibili Client_x.x.x_x64-setup.exe`，双击安装，扫码登录，开看。
