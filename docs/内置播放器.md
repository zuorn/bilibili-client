# 内置播放器

## 使用方法

- [ ] 鼠标左键点击可以直接拖动窗口
- [ ] 打开播放窗口默认窗口比例根据视频比例显示
- [ ] 快捷键
  - [ ] f 和 回车 进入全屏
  - [ ] q 退出
  - [ ] 空格暂停/播放
  - [ ] 左右键快进快退，上下键调整音量，m静音键
  - [ ] ctrl + tab 移动到下一个显示器
  - [ ] wasd上下左右移动播放窗口位置
