# Vim 风格快捷键设计文档

## 1. 设计理念

本方案基于 Vim 编辑器的操作哲学，将 Bilibili 客户端的操作分为多个模式，通过模式切换实现高效的键盘操作体验。

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **模式化** | 区分普通模式、插入模式、播放器模式，避免快捷键冲突 |
| **直觉性** | 沿用 Vim 经典按键（h/j/k/l 导航、gg/G 跳转等） |
| **高效性** | 单键或组合键操作，减少按键次数 |
| **可配置** | 支持用户自定义快捷键映射 |

### 1.2 模式分类

| 模式 | 进入方式 | 说明 |
|------|----------|------|
| **普通模式 (Normal)** | 默认进入 / `Esc` | 主要导航和操作模式 |
| **插入模式 (Insert)** | `i` / 点击输入框 | 文本输入模式 |
| **播放器模式 (Player)** | 打开视频播放器 | 视频播放控制模式 |

## 3. 快捷键优先级说明

### 3.1 模式优先级

1. **插入模式** > **播放器模式** > **普通模式**
2. 当输入框获得焦点时，自动进入插入模式
3. 当播放器窗口激活时，优先使用播放器模式快捷键

### 3.2 冲突处理

| 冲突场景 | 处理方式 |
|----------|----------|
| 全局快捷键 vs 页面快捷键 | 全局快捷键优先（如 Ctrl+q 始终退出应用） |
| 播放器快捷键 vs 页面快捷键 | 播放器激活时播放器快捷键优先 |
| 用户自定义 vs 默认 | 用户自定义优先级最高 |

## 5. 配置建议

### 5.1 默认配置

建议将 Vim 风格快捷键设置为可选模式，用户可在设置中开启/关闭。

### 5.2 配置文件格式

```json
{
  "vimModeEnabled": true,
  "shortcuts": {
    "normal": {
      "h": "navigateLeft",
      "j": "scrollDown",
      "k": "scrollUp",
      "l": "navigateRight",
      "gg": "goToTop",
      "G": "goToBottom"
    },
    "player": {
      "space": "togglePlay",
      "l": "seekForward",
      "h": "seekBackward",
      "f": "toggleFullscreen"
    }
  }
}
```

## 7. 实现建议

### 7.1 代码结构

```
src/renderer/features/
├── shortcuts.js          # 现有快捷键系统
├── vim-shortcuts.js      # Vim 风格快捷键模块
└── mode-manager.js       # 模式管理模块
```

### 7.2 模式管理流程

```
┌─────────────────────────────────────────────────────────────┐
│                    键盘事件监听                              │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                   判断当前模式                              │
│   [输入框聚焦?] → INSERT 模式                              │
│   [播放器激活?] → PLAYER 模式                              │
│   [其他]       → NORMAL 模式                               │
└───────────────────────────┬─────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│               根据模式分发快捷键处理                         │
│   NORMAL → 执行导航/页面操作                               │
│   INSERT → 传递给输入框                                    │
│   PLAYER → 执行播放控制                                    │
└─────────────────────────────────────────────────────────────┘
```

## 9. 设计总结

本设计方案遵循以下核心思想：

1. **模式区分**：通过模式切换避免快捷键冲突
2. **Vim 习惯**：沿用 Vim 经典按键，降低学习成本
3. **上下文敏感**：同一按键在不同模式下有不同功能
4. **渐进增强**：保留原有快捷键，增加 Vim 风格选项

通过这套 Vim 风格快捷键，用户可以在不离开键盘的情况下高效浏览和操作 Bilibili 客户端，获得类似 Vim 编辑器的流畅操作体验。
